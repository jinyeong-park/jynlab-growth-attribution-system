# 📂 How to Run

In the terminal of the project folder, install the dependency packages with the following command:

```bash
pip install pandas numpy

```

Copy the code above and save it as scripts/generate_synthetic_data.py.

Go to the folder one level above the scripts folder, then run the script in the terminal:

```

python scripts/generate_synthetic_data.py

```

Once execution is complete, 3 CSV files will be generated in the data/raw/ folder, and you can proceed directly to the next step: SQL cleaning and data loading (01_data_cleaning.sql)!
