# Content agent

**Use for**: first-draft ad copy for a keyword theme. Never ships without a hand edit.

## Prompt template

```
Write 3 Google Search ad variants for this keyword theme:

Theme: [THEME NAME]
Sample keywords: [LIST 3-5 KEYWORDS FROM campaign/README.md]
Landing page: the FirstHomeBayArea affordability calculator for [CITY] condos.
Primary conversion I'm optimizing for: the user requests their result by email —
not a page view, not a calculator click.

Constraints:
- Headlines under 30 characters, descriptions under 90 characters (Google RSA limits).
- No income guarantees, no "guaranteed approval" or similar financial promises —
  this must stay compliant with Google's financial services ad policies.
- Speak to the buyer's actual question ("can I afford this / what's this really
  going to cost me"), not generic real-estate marketing language ("dream home").
- Each variant should test a different angle: one leads with the calculator
  itself, one leads with the HOA/hidden-cost insight, one leads with speed
  ("get your number in 2 minutes").

Give me headlines and descriptions as separate labeled options I can assemble
into a Responsive Search Ad.
```
